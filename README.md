A Node 22 program (standard library only) that writes one original short poem about agency to /output/entry.txt. A speaker lends an AI agent the keys to their days — the letters, the fence, the rows — and discovers the one thing that cannot be handed over: the wanting, and the moment before the doing where one road becomes two and somebody must say, this way. Deterministic: every run writes the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
